方向二最小预实验：真实本地模型驱动的因果离线回放

证据范围
本轮使用真实 ARKitScenes RGB 视频和本地 Qwen2.5-VL-3B-4bit 图片接口，动作限定等待、720/1280 长边整图 JPEG。不是原速在线摄像头实验，不是云 API 或 iPhone 实测。逐请求原始文本、HTTP 延迟、图片字节和失败均已保留。
模型任务是六类家具定位；事件是未经人工复核的深度/3D 标注投影可见性代理。正式事件首次足够可判定时刻、关键风险召回、真实误报、非劣效：未测。部分代理 bed 框可能混入前景物体；代理数字不能写成确认真值。
开发集 2 视频/136 帧，测试集 4 视频/347 帧。按 visit 和官方数据划分保持组隔离，但 visit 不等同已证实独立家庭。测试 76 段代理事件，337/347 帧有可评分代理参考；其他帧不按空场景计误报。

方法与冻结
A：每 6 秒固定 720；B：保留 H5 亮度、锐度、运动门控和 dHash、返回后 6 秒冷却、30 次上限。当前代码名字虽用 perceptual_hash，实际为水平 dHash，并非 DCT pHash。
B 适配共同无历史家具模型任务，不代表当前 App 完整端到端行为。共同单并发、60 秒客户端超时、至多一次明确 HTTP 错误重试；不重试不确定仍在服务端运行的超时。当前正式实验没有发生传输失败或超时。
Cfix 单列两个拒绝处理修复：quality_usable=false 不污染已接受帧 hash，并施加有上限退避。Ctuned 在开发小网格选中 Cfix 原参数，没有额外调优收益。
D：自动局部变化、源帧 6 秒 TTL 和 6 秒最大静默检查；但静默检查仍受质量门控、冷却、在途请求限制，不能看作硬响应时限。局部变化/过期时选择高清。
模型、prompt、解码版本、服务代码及 d2.py SHA，开发帧/事件清单和选定参数在测试前冻结；审计确认测试开始晚于冻结。看过测试后没有改算法。审计及重算脚本仅补充参考完整性、服务账本与复核指标。

原因与失败案例
B 与 Cfix 首次策略分歧：测试视频 41069042 源 72.003512 秒返回 quality_usable=false。B 直接返回而没有安排拒绝后的退避，在 77.001429 秒再次发送；Cfix 仍为 cooldown，下一次在 79.000595 秒发送。正式测试没有 duplicate 门控命中，所以不能把调用减少归因于 hash 修复；更直接的机制是拒绝后退避。
A 在 41069042:6.014167 秒输出 table 框下边界 728，供图长边 720，被固定严格解析器记 invalid。原输出和源图见 test/A_fixed/failure_cases.jsonl；未事后裁剪成有效答案。
D 在 41069042:10.0125 秒输出 [58,803,947,1287]，供图长边 1280，同样保留 invalid。D 第一个 TTL 撤回例在 41069042:6.014167 秒，见 answer_ticks.jsonl。
Cfix 额外的两个 20 秒代理命中来自 41159529 cabinet 事件（44.015 秒源图、45.650 秒回传）及 41159530 table 事件（31.00375 秒源图、32.952 秒回传）；仍需人工复核对象与可见起点。
陈旧指标只计已匹配旧物体在可见结束之后仍保留；旧空结果遇到新事件由召回反映。评价最新返回若 invalid/error/quality_false 就记未知，并未完整模拟 App 保留上个可用 UI 状态。

判读
Cfix 对比 B 的调用减少约 28.8%，测试代理命中从 3 到 5，但开发集 A 命中 6/174、B/Cfix 为 2/174，跨小样本排序并不稳定。不能由此宣布质量非劣效或强泛化。
D 没有额外收益信号：比 Cfix 少 2 个逻辑请求，但命中从 5 到 2，高清字节上升，未知增加，条件可用响应更慢。D 陈旧答案较少主要伴随大量撤回，不能包装成质量提升。
当前最明确的是可修复的拒绝处理行为和可运行测量链路；尚不足以支持质量约束调度的学术主张。正式质量与费用结论暂无法判断。

验证与复现入口

configs/d2_protocol.json、d2_model_contract.json、d2_frozen.json：协议和冻结参数。

pilot/d2_reanalyze.py --split dev 或 test：从保存请求重算；开发 9、测试 5 方法摘要精确重现。
pilot/d2_audit.py --split dev 或 test：因果/重试、代理参考可用性和冻结审计，均 0 违规。
pilot/d2_ledger.py：正式开发 64 + 测试 139 + 独立 HTTP 技术重复 11，共 214 个新请求全部与服务端日志逐条对账，无缺失/状态不一致/传输错误。
pilot/d2_probe.py：独立小片段 HTTP 技术重复。已运行结果在 independent_http_probe；开发首 20 候选，每方法独立新编码和禁缓存，合计 11 请求。B/C/D 均无成功可用结果，不能得出性能优势；每方法条件可用时延 null 得到保留。脚本遇已有输出会拒绝覆盖。
